# Atlas Demo Project

## 本地启动

项目使用 Docker Compose 启动 MySQL、FastAPI 后端和 Vue 前端。后端默认运行在 8000 端口，前端默认运行在 5173 端口。

## 新成员上手顺序

1. 先阅读 README，了解启动命令和目录结构。
2. 再阅读架构文档，确认前后端边界和数据流。
3. 使用示例文档完成一次上传和问答。
4. 最后查看 API 文档和测试用例。

## 项目上下文

Atlas 将项目文档按重叠窗口分块，并使用混合检索找到与问题最相关的内容。回答必须携带来源；当知识库没有足够证据时，Agent 应该明确提示用户，而不是编造答案。
